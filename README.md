# نظام تقارير الزيارات الميدانية — نسخة مستقلة

هذه نسخة محلية قابلة للتشغيل في **VS Code** والعمل عليها بواسطة **GitHub Copilot**. لا تعتمد النسخة على نطاق Manus أو واجهات Forge أثناء التشغيل الأساسي؛ تستخدم MySQL/MariaDB لقاعدة البيانات وتخزينًا محليًا في مجلد `uploads/`، ويمكن استبدال التخزين لاحقًا بـ S3 أو MinIO أو خدمة تخزين خاصة.

> تنبيه أمني: تبدأ النسخة بوضع تجربة لتسهيل التشغيل الأولي. قبل استخدامها مع بيانات حقيقية، يجب ضبط `DEMO_MODE_ENABLED=false` وإضافة طبقة مصادقة إنتاجية مناسبة للمؤسسة، مع HTTPS ونسخ احتياطية لقاعدة البيانات ومجلد الصور.

## المتطلبات

يحتاج التشغيل المحلي إلى Node.js 20 أو أحدث، وpnpm 10 أو أحدث، وDocker Desktop عند استخدام قاعدة البيانات المرفقة. يمكن تشغيل MySQL خارجيًا بدل Docker بوضع رابط الاتصال في `.env`.

## التشغيل السريع

انسخ ملف البيئة النموذجي ثم شغّل قاعدة البيانات:

```bash
cp env.template .env
 docker compose up -d db
pnpm install
pnpm db:generate
pnpm db:migrate
pnpm dev
```

افتح `http://localhost:3000`. في الوضع التجريبي، يفتح التطبيق تلقائيًا بحساب مندوب تجريبي، ويمكن الانتقال إلى لوحة المدير من داخل الواجهة أو عبر `/manager`.

## المتغيرات الأساسية

| المتغير | الغرض |
|---|---|
| `DATABASE_URL` | رابط MySQL أو MariaDB الخاص بالمشروع |
| `JWT_SECRET` | مفتاح جلسات طويل وعشوائي، ويجب تغييره قبل الإنتاج |
| `PORT` | منفذ خادم Node |
| `UPLOAD_DIR` | مجلد تخزين الصور على الخادم |
| `DEMO_MODE_ENABLED` | `true` للتجربة فقط، و`false` قبل الاستخدام الفعلي |

## قاعدة البيانات والتخزين

المخطط موجود في `drizzle/schema.ts` والترحيلات في `drizzle/`. لا تُحفظ بايتات الصور داخل قاعدة البيانات؛ تُحفظ بياناتها الوصفية ورابطها فقط، بينما توضع الملفات في `UPLOAD_DIR`. في بيئة متعددة الخوادم، استخدم MinIO أو S3 خاصًا بدل التخزين المحلي لأن الملفات المحلية لا تكون مشتركة بين النسخ.

## النشر الخارجي

يمكن تشغيل المشروع على أي استضافة تدعم Node.js أو Docker. نفّذ `pnpm build` ثم شغّل `pnpm start`. يجب تمرير المتغيرات البيئية من لوحة الاستضافة، وعدم رفع `.env` أو الصور أو كلمات المرور إلى GitHub. عند استخدام Proxy أو Load Balancer، مرّر `X-Forwarded-Proto` واضبط HTTPS حتى تعمل الكاميرا والموقع الجغرافي في المتصفح.

## GitHub وVS Code

أنشئ مستودعًا خاصًا، ثم:

```bash
git init
git add .
git commit -m "Initial portable field visits app"
git branch -M main
git remote add origin <PRIVATE_REPOSITORY_URL>
git push -u origin main
```

بعد فتح المشروع في VS Code، يمكن استخدام GitHub Copilot لتطوير المصادقة، الفلاتر، التقارير، والنسخ الاحتياطي مع إبقاء الأسرار في `.env` أو Secrets الخاصة بمنصة الاستضافة.

## قبل الإنتاج

اختبر تسجيل الدخول الحقيقي، صلاحيات المدير، رفع الصور، صلاحيات الموقع والكاميرا، النسخ الاحتياطي والاستعادة، وحدود حجم الطلبات. كما يجب استبدال وضع التجربة بمصادقة حقيقية مثل OIDC أو Auth.js أو مزود هوية مؤسسي قبل إدخال بيانات العملاء.
